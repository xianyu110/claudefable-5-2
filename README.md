# ClaudeFable五点二刚刚上线！

大半夜的，没等来 GPT-6.2 Sol，刚准备睡。

然后，AIHOT 小助手在飞书群里啪的一下给我弹了个消息。

好的，这下不用睡了。

凌晨 3 点，Claude 终于正式发布了 Claude Fable 5.2。

与此同时，OpenAI 今晚正在卖 200 刀的掌机。

叫你上周不发 GPT-6.2 Sol，明明口碑那么好，这下不尴尬了吗。。。

目前 Claude Fable 5.2 已经在全渠道正式上线，我的 Claude 桌面端里，已经能看到了。

![Claude 桌面端已出现 Fable 5.2](https://upload.maynor1024.live/file/1794273304310_00.png)

同时，这一次 Anthropic 也给 20 刀的 Pro 会员开放了 Fable 5.2 的临时使用权限，不过只限这一周。

同时也为 Claude 的 200 刀的 Ultra 订阅用户，送上了一次 Fable 的额度重置机会，根据订阅时间来，并且有效期一直到明年的 3 月 8 号，讲道理，A 在有些时候，还是怪良心的。。。

我也收到了。

![Ultra 额度重置通知](https://upload.maynor1024.live/file/1794273308378_01.png)

这里大家可以记一下我的额度剩余，我是 200 刀的 Ultra 会员，在使用 Claude Fable 5.2 测试之前，我的额度还剩 30%。

![测试前额度剩余约 30%](https://upload.maynor1024.live/file/1794273302621_04.png)

还是非常开心，在爽用了近一个半月的 Claude Opus 5.5 之后，终于等来了新的 Fable 模型，只不过不是传言中的 Claude Fable 5.5，Anthropic 给它命名成了 Claude Fable 5.2。

这个其实也正常，最早是 9 月 9 号，就有人爆料说 Anthropic 在跑一个新模型，当时给出的临时代号，还真就叫 Fable 5.2，但后来 Opus 5.5、Sonnet 5.5 一个个都出来了，大家很自然就顺着往下推，下一个 Fable，那肯定也得叫 5.5 吧，结果最后是 5.2，所以大概率 Anthropic 还藏着一手更强的 Fable 5.5。

先看一下 Fable 5.2 的基本情况。

Claude Fable 5.2 依然拥有 1M，也就是 100 万 Token 上下文，最大输出 128K Token，知识截止时间到了 2026 年 6 月。

价格这次反而走了降价风，现在大家也都知道，Token 太贵了，已经超出全人类的接受范围了，所以涨价潮过去，现在也都开始在不断降价了。

Fable 5.1 原来是每百万 Token 输入 10 美元、输出 50 美元。

Fable 5.2 变成，输入 8 美元，输出 40 美元，缓存也差不多，整体降价了 20%。

几个 Anthropic 家的主力模型价格对比，大概是这样的。

![Anthropic 主力模型价格对比](https://upload.maynor1024.live/file/1794273304978_02.png)

![Fable 5.2 价格与规格说明](https://upload.maynor1024.live/file/1794273300404_03.png)

![规格补充说明](https://upload.maynor1024.live/file/1794273304272_05.png)

然后在速度上也快了一些，官方说是比 Fable 5.1 最多快了 30%，没有特别多，只能说聊胜于无吧。

然后就是被误伤的次数少了，Fable 那套安全护栏一直被人诟病，6 月刚出的时候很多人就在骂，说它把生物作业都当成安全威胁，那这次官方说误拦截比 5.1 少了大约 55%，网络安全类少 60%，生物类少 40%。

还有个点是我用下来蛮喜欢的一点，算是继承了 Opus 5.5 的优势，就是终于开始说一些人话了，之前 Fable 5.1 的输出风格跟 Opus 5 那个满嘴黑话的感觉有的一比，我用的特别不喜欢，完全看不懂在说什么，后来 Opus 5.5 的时候，Anthropic 终于迷途知返，知道哦模型是给人用的，所以交流感和说人话特别重要，于是大调优了一下，瞬间口碑就回来了。

这次 Fable 5.2 也继承了 Opus 5.5 的优点，说话风格如出一辙。

![Fable 5.2 回复风格示例](https://upload.maynor1024.live/file/1794273301850_07.png)

不过从这段回复中也能看出，Claude 系列模型的高高在上感因为 Fable 的能力加强，也更加加剧了。

因为最近做的东西确实太多了，有些涉及到底层基建，有点乱，所以它这次直接推翻了我的想法，告诉我有一个更好更合适的做法，应该把我改的东西直接接入到通用的中台插件里面去，而不是还在改之前的那个破壁 CI 中台。

我之前就发过一个还挺火的关于 Claude 和 GPT 两个模型性格区别的段子。

「我：每周都要从后台下载 20 个 Excel，再手动复制粘贴成一张总表，太麻烦了，帮我写个自动操作鼠标的脚本。

GPT： 好的老板！已经帮你写好了，自动点击、下载、复制、粘贴，还加了异常处理和失败重试，以后你只需要点一下运行就行！

Claude： 不是哥们，你这 20 个 Excel 不都是从同一个数据库里导出来的吗？你好好的你下载它们干啥？我直接帮你写了个 SQL，接上你们后台的数据源了，以后每周自动生成最终报表，你说你好好的下载 Excel 干什么玩意。。。」

对我这种比较菜鸡，希望模型能力更强，能说出一些我不知道的事的人来说，那么 Claude 其实反而会更适合我，有人称为许愿式编程，当然，也可以称为，与神对话。

跑分上，不用想，Fable 系列在今天，基本上就是出手必 SOTA 的。

AA 指数上以 65 分登顶。

![AA 指数相关](https://upload.maynor1024.live/file/1794273309507_08.png)

![AA 指数 65 分登顶](https://upload.maynor1024.live/file/1794273305507_09.png)

官方的跑分也是，基本碾压所有，而且主要是 Anthropic 的跑分，你是可以真信的。

![官方综合跑分](https://upload.maynor1024.live/file/1794273311710_10.png)

跑分我就不一个个念了。

Anthropic 也搞了一个非常有趣的实验，让 Fable 5.2 承担设计一个原型操作系统的任务，直接从空文件夹开始，协调了 1000 多个子智能体，连续八天昼夜不停地编写、测试和审查代码，然后，它产出了一个可运行的操作系统，能在笔记本电脑上启动，拥有运行机器的自有内核、磁盘、键盘和网络驱动、永久文件存储、窗口、登录界面、安装程序，以及内置的 Claude 功能。。。

这种非常硬核的测试，肯定是超出我们的能力范围了。

在有限的额度下，我还是把重点，放在了 Opus 5.5 的最长板上，视频动效，以及前端审美。

（PS：声明一下，以下 Case 全部为一次直出，我没有做任何二次对话，没有做任何后期加工，全部是我一个 Prompt 过去，他跑 2 小时，给我的结果，我没有做任何的二次处理。）

首先，我第一个想到的，其实就是本来为 GPT-6.2 Sol 准备的一个 Case，马上不就是 ChatGPT 四周年了嘛，所以也想做一个 ChatGPT 这四年历史的一个视频，这次就准备让 Claude Fable 5.2 直出了，一是可以看幻觉率，二是可以看审美，三是可以看代码的精准性，四是 NTR 的剧情实在是太好看了。

我的 Prompt 特别简单：

「做一支 40 秒到 1 分钟的 ChatGPT 四周年致敬动效视频（2022.11.30–2026.11.30），16:9 横版，无旁白，配原创音乐。内容自己联网查证，讲这四年的关键版本、里程碑和数字，不得杜撰。动手前先去 OpenAI 官网、博客和近期发布视频里观察他们的视觉风格，提炼后作为这支片子的视觉基调。节奏要快，动效密、画面饱满，随音乐卡点。片子定位是第三方致敬，不要做成 OpenAI 官方出品的样子。」

然后，他就去做了。在干了将近 1 小时之后，Claude 给了我一个这样的视频。。。

![ChatGPT 四周年致敬动效预览](https://upload.maynor1024.live/file/1794273323110_11.gif)

![视频相关说明](https://upload.maynor1024.live/file/1794273312457_12.png)

讲道理，我一时不知言语为何物了。

我确实对着里面的信息，一点一点的去验证了，然后悲哀的发现，我没有挑出任何一个事实错误。

信息是 Fable 5.2 自己搜的，平面是他自己做的，配乐是他自己写的，卡点是他自己卡的，动效是他自己的做的，剪辑是他自己剪的。

讲道理，最后这个画面，我是真的一下子没绷住。

看着这个视频，我当时真的陷入了深深的沉思。。。

然后，他就开始查真实照片，来给他自己做参考。。。

![查阅参考照片](https://upload.maynor1024.live/file/1794273309455_24.png)

看完了以后，终于觉得差不多了，开始建模了。

我其实内心很忐忑，因为我不知道它能干出来个什么级别的东西。

我们公司里一个之前学建筑的小伙伴，看完了之后，直接爆出了人类最原始的那个字。

因为我发现它真的是在认真仿造着进行建模的，对此我还专门找了一张 Apple 静安的室内效果图进行对比。

注意这是一张正常视角，一张其实可以算作广角了。

![与真实室内效果图对比](https://upload.maynor1024.live/file/1794273312991_29.png)

虽然不能说完全一样，但从建模中的材质表现，空间的还原和大致的比例关系，都做的非常牛逼。

除了核心的材质表现和内部空间还原的非常好外，Fable 5.2 还将细节尽可能延伸到了室外的这个圆形下沉广场：

![圆形下沉广场细节](https://upload.maynor1024.live/file/1794273319673_30.png)

只能说，Fable 5.2 在审美和细节这块，确实太强太强了。

我大概跑了 10 个任务，基本都是 Fable 5.2 Xhigh，大家还记得我最开始跟大家说的，我在跑测试之前，额度还剩多少吗。

那时候，还剩 30%，我用了 70%。

而现在，卡在了 94%。

![额度消耗到约 94%](https://upload.maynor1024.live/file/1794273321050_32.png)

将近 4 个小时，10 个任务，怼掉了我差不多 24% 的额度，Fable 的使用量差不多用完了 50%。

有一说一，贵是真贵啊。

所以 Fable 这个模型，虽然是 SOTA，能力确实强，但是价格摆在这里，没办法，所以日常大概率依然还是 Opus 5.5 和马上要发的 GPT-6.2 Sol（我已经灰度体验 2 天了，性价比极高，能跟 Opus 5.5 比一比）为主了，Fable 5.2 只适合最大的诊断规划，以及做指挥型模型，审美和前端相关交给 Opus 5.5 做，算法和后端相关交给 GPT-6.2 sol 做，可能是我自己认为的最优解。

![模型分工总结](https://upload.maynor1024.live/file/1794273316793_33.jpg)

讲道理，Fable 5.2 这种模型，才是 Personal agent 的最棒的模型，就像你是皇上，他是宰相，他根据你的喜好和目标，猜你所想，然后指挥其他的大臣来干活，这个就太合适不过了，额度也不会烧的特别多。

大概就是这样了。

比如，开始尝试用代码的方式来画图。

感觉每一次大模型的进步，都能给大家，带来更多的想象力。
